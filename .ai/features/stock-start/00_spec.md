# 00_spec - stock-start

작성: Codex
일시: 2026-05-28

## 기능 목표
- WPF 데스크톱 앱에서 코스피 지수, SK하이닉스, 삼성전자 주가를 주기적으로 갱신해 화면 상단에 보여주고, 그 아래에 환율과 금시세를 함께 표시한다.
- C# 프로젝트는 MVVM 구조와 Prism 기반 앱 구성을 사용해 UI, 상태, 데이터 조회 로직을 분리한다.

## 기능명
- feature_name: stock-start
- naming_reason: 하네스에서 잠긴 기능명이며, 주식/시세 화면의 시작 기능을 나타내는 짧은 slug이다.

## 구체적 요구사항
- 루트 `src/` 하위에 WPF C# 애플리케이션 프로젝트를 만든다.
- 앱은 Prism 기반 부트스트랩/DI 구성을 사용한다. 기본값은 Prism WPF에서 일반적으로 쓰이는 `Prism.DryIoc` 또는 동등한 Prism 컨테이너 패키지이다.
- UI는 MVVM 패턴을 따른다. View는 화면 배치와 바인딩만 담당하고, ViewModel은 표시 상태와 명령을 담당하며, 외부 시세 조회는 서비스 계층으로 분리한다.
- 표시 대상은 다음 5개 항목이다.
  - 코스피 지수
  - SK하이닉스 보통주, 기본 종목코드 `000660`
  - 삼성전자 보통주, 기본 종목코드 `005930`
  - 환율, 기본 통화쌍 `USD/KRW`
  - 금시세, 기본 표시는 원화 기준 g당 가격이며 데이터가 국제 금시세만 제공되면 환율을 적용해 환산값을 표시한다.
- 각 시세 항목은 이름, 현재가/지수값, 전일 대비 값, 전일 대비율, 최종 갱신 시각, 조회 상태를 표시한다.
- 앱은 시작 후 자동으로 데이터를 조회하고, 수동 새로고침 명령도 제공한다.
- "실시간"은 API 키가 없는 기본 구현 기준으로 틱 단위 스트리밍이 아니라 주기적 갱신으로 정의한다. 기본 갱신 간격은 5초이며, 실패가 반복되면 짧은 백오프 후 재시도한다.
- 조회 중, 조회 성공, 조회 실패 상태를 UI에 명확히 반영한다.
- 네트워크 오류, 파싱 오류, 일부 항목 조회 실패가 발생해도 앱 전체가 종료되지 않아야 한다. 실패한 항목은 마지막 성공값 또는 오류 메시지를 표시한다.
- 데이터 공급자는 인터페이스로 추상화해 이후 공식/유료 API로 교체할 수 있게 한다.
- API 키나 비밀값을 코드에 하드코딩하지 않는다.
- 다음 단계에서 테스트를 추가할 경우 테스트 코드는 루트 `tests/` 하위에 둔다.

## 이번 범위에서 제외하는 것
- 매수/매도 주문, 계좌 연동, 인증, 개인 포트폴리오 관리는 제외한다. 현재 요청은 시세 표시 프로그램 생성에 한정된다.
- 투자 판단 알림, 백테스트, 차트 분석, 뉴스 수집은 제외한다. 초기 화면의 안정적인 시세 표시가 우선이다.
- 틱 단위 거래소 스트리밍 보장은 제외한다. 무료/무자격 증명 데이터 소스에서는 안정적으로 보장하기 어렵기 때문이다.
- 배포 설치 프로그램 생성은 제외한다. 프로젝트 생성과 실행 가능한 개발 빌드 구성이 우선이다.

## 입력과 출력
- 입력 형태:
  - 사용자가 직접 입력해야 하는 값은 기본 범위에 없다.
  - 내부 기본 설정값은 종목코드 `KOSPI`, `000660`, `005930`, 통화쌍 `USD/KRW`, 금시세 단위 `KRW/g`, 갱신 간격 5초이다.
  - 향후 확장을 위해 앱 설정 파일 또는 DI 등록값으로 종목/통화/갱신 간격을 바꿀 수 있는 구조를 허용한다.
- 출력 형태:
  - WPF 메인 화면에 시세 카드 또는 행 목록 형태로 표시한다.
  - 각 행은 표시명, 값, 등락, 등락률, 갱신 시각, 상태를 포함한다.
- 비정상 입력 및 오류 처리:
  - 잘못된 종목코드나 통화쌍은 해당 항목만 오류 상태로 표시한다.
  - 네트워크 실패, 응답 지연, 비정상 응답은 예외를 UI 스레드 밖에서 처리하고 사용자에게 조회 실패 상태를 보여준다.
  - 데이터가 없거나 일부 필드가 누락되면 앱은 종료되지 않고 가능한 필드만 표시하거나 `N/A`를 사용한다.

## 기술적 제약
- 언어/플랫폼: C#, WPF, .NET 데스크톱.
- 아키텍처: MVVM, Prism 기반 모듈/DI/명령/바인딩 패턴.
- 외부 데이터 조회는 `HttpClient` 기반 비동기 처리로 구현한다.
- UI 갱신은 WPF UI 스레드 규칙을 지켜 처리한다.
- 새 외부 NuGet 의존성은 Prism 사용을 위해 필요할 수 있으며, 시세 응답 파싱을 위해 JSON/HTML 파서 의존성이 추가될 수 있다.
- 무료 공개 데이터 소스는 응답 형식 변경이나 요청 제한 가능성이 있으므로 공급자 교체 가능한 구조를 우선한다.
- 하드코딩된 비밀값, 계정 정보, API 키를 저장소에 추가하지 않는다.

## 기본 결정 기록
- 기본 시세 대상은 코스피 지수, SK하이닉스 `000660`, 삼성전자 `005930`으로 확정한다. 사용자가 명시한 이름을 한국 시장의 대표 종목코드로 해석했다.
- 기본 환율은 `USD/KRW`로 확정한다. 한국 주식과 금시세 화면에서 가장 일반적인 기준 환율이다.
- 기본 금시세 단위는 `KRW/g`로 확정한다. 한국 사용자에게 직접적인 표시 단위이며, 원천 데이터가 국제 금시세이면 환율로 환산 가능하다.
- 기본 갱신 방식은 5초 polling으로 확정한다. "실시간" 요구를 개발 가능한 수준으로 만족하면서 무료 데이터 소스의 제약을 반영한 보수적 기본값이다.
- 데이터 공급자는 교체 가능한 서비스 인터페이스로 확정한다. 무료 공개 소스의 안정성 리스크와 향후 공식 API 전환 가능성을 줄이기 위함이다.
- UI는 단일 메인 화면으로 확정한다. 요청 범위가 시세 표시 프로그램의 첫 화면에 집중되어 있기 때문이다.
